# Jiayang Liu Portfolio

A lightweight static portfolio designed for GitHub Pages.

## Repository
`jiayanggliu.github.io`

## Local preview
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

## Update workflow
- Add a project card in `index.html`.
- Keep project code in its own GitHub repository.
- Link each card to the repository and, when available, a live dashboard.
- Add resume/contact links when ready to publish them.
